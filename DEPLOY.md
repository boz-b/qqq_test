# Deployment Guide — QQQ Intraday Dashboard (Pi + Vercel)

## Architecture Overview

```
Raspberry Pi (always-on)                  GitHub repo
─────────────────────────                 ───────────────────────
cron runs export_json.py                  public/
  nightly after market close      push →    data/
    → refreshes CSV data                      dates.json
    → pre-computes all charts                 2026-02-10.json
    → writes public/data/*.json               2026-02-11.json
                                              …
                                          index.html
                                              ↓ auto-deploy
                                        Vercel CDN (free)
                                          https://your-app.vercel.app
```

The Raspberry Pi does all the heavy lifting (yfinance, cloudscraper, pandas).
Vercel serves only pre-computed static files — zero server-side code.
The date picker on the page is fully interactive: each selection fetches
a different pre-computed `YYYY-MM-DD.json` file from Vercel's CDN.

## Part 1 — GitHub Repository Setup

### 1.1 Create a GitHub repository

1. Go to https://github.com/new
2. Name it `qqq-dashboard` (or any name you like)
3. Set visibility to **Private** (recommended — contains financial data)
4. Do **not** initialise with a README — you already have code
5. Click **Create repository**

### 1.2 Push the project from the Pi

```bash
cd ~/qqq_test
git remote add origin git@github.com:YOUR_USERNAME/qqq-dashboard.git
git push -u origin main
```

### 1.3 Verify .gitignore excludes raw data CSVs

The raw CSV files (`qqq_1m.csv`, `qqq_daily.csv`, `ff_events.csv`) should
**not** be committed — they are large, change daily, and are regenerated by
`export_json.py`.  Check your `.gitignore` contains:

```
*.csv
__pycache__/
venv/
logs/
```

## Part 2 — Vercel Setup (one-time, ~5 minutes)

### 2.1 Create a Vercel account

Sign up at https://vercel.com using your GitHub account.
The free Hobby plan is sufficient — no credit card required.

### 2.2 Import the GitHub repository

1. In Vercel dashboard → **Add New Project**
2. Select **Import Git Repository** → choose `qqq-dashboard`
3. Vercel will detect `vercel.json` automatically
4. **Framework Preset**: select **Other**
5. Leave all other settings as defaults
6. Click **Deploy**

Vercel will build and deploy in ~30 seconds.
Your dashboard URL will be `https://qqq-dashboard-XXXX.vercel.app`
(you can set a custom domain in Vercel settings later).

### 2.3 Verify the first deploy

Open the URL — you should see the dashboard load with whatever dates are in
`public/data/dates.json`.  If `public/data/` is empty, run `export_json.py`
manually first (see Part 3).

## Part 3 — Raspberry Pi Setup

### 3.1 Clone the repository on the Pi

```bash
git clone git@github.com:YOUR_USERNAME/qqq-dashboard.git ~/qqq_test
cd ~/qqq_test
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3.2 Configure SSH key for passwordless git push

The cron job needs to push to GitHub without a password prompt.

```bash
# Generate a key (if you don't already have one)
ssh-keygen -t ed25519 -C "pi-qqq-dashboard"

# Print the public key
cat ~/.ssh/id_ed25519.pub
```

Copy the output and add it to GitHub:
**Settings → SSH and GPG keys → New SSH key**

Test it:
```bash
ssh -T git@github.com
# Should print: Hi YOUR_USERNAME! You've successfully authenticated…
```

### 3.3 Set git identity on the Pi

```bash
git config --global user.email "you@example.com"
git config --global user.name "QQQ Pi Bot"
```

### 3.4 Run export_json.py manually (first-time test)

```bash
cd ~/qqq_test
source venv/bin/activate
python3 export_json.py
```

Expected output:
```
============================================================
export_json.py  2026-02-10 21:05:03
============================================================
Refreshing data via DataLoader.fetch_all() …
Data refresh complete.
Found 15 trading dates  (2026-01-22 … 2026-02-07)
  Written dates.json  (15 entries)
  2026-01-22.json  (181 bars, 589.10 prior close, 0 FF events)
  …
Pushed successfully on attempt 1.

Done. Vercel will auto-deploy within ~30 seconds.
```

After ~30 seconds, refresh your Vercel URL — the new data should appear.

### 3.5 Create the log directory

```bash
mkdir -p ~/qqq_test/logs
```

### 3.6 Install the cron job

```bash
crontab -e
```

Add this line — runs at 9 PM ET (02:00 UTC) on weekdays, well after the
4 PM ET market close and any after-hours data settling:

```cron
0 2 * * 2-6  cd /home/pi/qqq_test && venv/bin/python3 export_json.py >> logs/export.log 2>&1
```

> **Note on timezone**: cron uses the Pi's local clock.  If your Pi is set to
> UTC (Raspberry Pi OS default), `0 2 * * 2-6` = 9 PM ET (10 PM ET during EDT).
> Adjust the hour if your Pi uses a different timezone.

Verify cron is installed:
```bash
crontab -l
```

## Part 4 — Keeping Things Running

### How data flows after initial setup

```
Every weeknight at 9 PM ET:
  cron → export_json.py
    → DataLoader().fetch_all()     # yfinance + ForexFactory
    → writes public/data/*.json    # pre-computed charts + stats
    → git push                     # triggers Vercel auto-deploy
    → Vercel CDN updated           # live within ~30 seconds
```

### Checking the cron log

```bash
tail -50 ~/qqq_test/logs/export.log
```

### Manually triggering a refresh

```bash
cd ~/qqq_test && source venv/bin/activate && python3 export_json.py
```

### What the dashboard can do interactively

Even though the data is pre-computed, the date picker is fully interactive:
- Selecting a different date fetches the corresponding `YYYY-MM-DD.json` from
  Vercel's CDN — no round-trip to the Pi, no server required
- The Chart.js chart, PM stats panel, and FF events table all update instantly

## Part 5 — Troubleshooting

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| Page loads but no dates in dropdown | `public/data/dates.json` missing | Run `export_json.py` manually |
| Specific date missing from picker | That date had no intraday data | Check CSV covers that date |
| Vercel shows old data | git push failed on Pi | Check `logs/export.log`; re-run manually |
| `cloudscraper` blocked on ForexFactory | Cloudflare updated | Update `cloudscraper`: `pip install -U cloudscraper` |
| yfinance rate-limit error | Too many requests | Data refresh retries automatically; wait and re-run |
| SSH push asks for password | SSH key not set up | Repeat step 3.2 |

### Vercel deploy logs

In the Vercel dashboard → your project → **Deployments** tab.
Each git push creates a new deployment entry with build + function logs.

## Part 6 — Optional Enhancements

### Custom domain

In Vercel → Project → **Settings → Domains** → add your domain.
Vercel provisions a free TLS certificate via Let's Encrypt automatically.

### Vercel password protection

To keep the dashboard private without making the repo public:

Vercel dashboard → Project → **Settings → Deployment Protection** →
enable **Password Protection** (requires Vercel Pro, $20/mo).

Free alternative: keep the repo private + share the `.vercel.app` URL only
with people you trust (the URL is not guessable but is not authenticated).

### Extend the date range

The current `export_json.py` exports all dates in the intraday CSV.
yfinance caps 1-minute data at 30 calendar days.  To maintain a longer history,
run `export_json.py` at least once every 25 days — the existing JSON files
accumulate in `public/data/` and are never deleted by the script.
